Project for the OOP Practicum course in FMI.

-The game features a turn based battling system with 3 classes of heroes each with different abilities and stats.

-There is a shop where Users can buy special items which can be used in battle by their heroes or level ups.

-The project also features a ranklist for all the registered users sorted by number of wins/Total xp/win percеntage.

-The game state is saved when you exit through the option in the main menu so the progress of every user and their items are saved for future battles.
